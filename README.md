# VebUp Showcase

Build a complete, production-ready, modern business website for my web design and development company **VebUp**.

## Brand

**Brand Name:** VebUp
**Tagline:** We Build. You Grow.
**Primary Domain:** vebup.in
**Business Email Domain:** vebup.info
**Primary Contact Email:** [info@vebup.info](mailto:info@vebup.info)

VebUp provides professional websites and digital solutions for **small businesses and local businesses**. The website should feel trustworthy, premium, modern, fast, and conversion-focused.

---

# DESIGN DIRECTION

Create a **premium LIGHT / WHITE theme only**.

Do NOT use a dark theme.

Visual style:

* White and off-white backgrounds
* Very clean layouts
* Black / charcoal typography
* One professional accent color inspired by a modern technology brand
* Subtle gradients
* Large whitespace
* Rounded cards
* Soft shadows
* Premium borders
* Modern typography
* Minimal but beautiful visual effects
* High-end SaaS/agency aesthetic

The website should look like it was designed by a professional product design agency, not like a generic AI-generated template.

Use a consistent design system across the entire website.

---

# ANIMATIONS

Animations are extremely important.

Use **smooth, subtle, premium animations**, never excessive or distracting.

Implement:

* Smooth page-load animation
* Hero text reveal
* Staggered element animations
* Fade-up sections
* Smooth card hover effects
* Image reveal animations
* Button hover transitions
* Navbar transition on scroll
* Subtle floating elements
* Smooth section transitions
* Portfolio hover interactions
* Scroll-triggered animations
* Number/count-up animation where appropriate
* Micro-interactions on buttons and cards

Use modern animation techniques such as **Framer Motion** where appropriate.

Animations should feel similar to premium modern SaaS/agency websites.

Respect `prefers-reduced-motion`.

---

# RESPONSIVE DESIGN

The website must be fully responsive.

Optimize for:

* Desktop
* Laptop
* Tablet
* Mobile

Mobile design must not simply be a compressed desktop layout. Create proper mobile spacing, typography, navigation, buttons, cards and layouts.

The website should feel excellent on a 360px-wide mobile screen.
